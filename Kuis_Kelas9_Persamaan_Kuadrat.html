Lembar Rumus Persamaan Kuadrat

1. Bentuk Umum & Pemfaktoran

Bentuk umum: $$ax^2 + bx + c = 0, \quad a \neq 0$$

Selisih dua kuadrat: $$x^2 - y^2 = (x + y)(x - y)$$

Faktorisasi $a=1$: $x^2 + bx + c = (x+p)(x+q)$ dengan $p+q=b$ dan $p \cdot q = c$.

2. Melengkapkan Kuadrat Sempurna

Ubah ke bentuk $x^2 + mx = n$, lalu tambahkan kedua ruas dengan $\left(\frac{1}{2}m\right)^2$:

$$\left(x + \frac{m}{2}\right)^2 = n + \left(\frac{m}{2}\right)^2$$

3. Rumus ABC & Diskriminan

$$x_{1,2} = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

Diskriminan: $$D = b^2 - 4ac$$

  • $D > 0 \Rightarrow$ dua akar real berbeda
  • $D = 0 \Rightarrow$ dua akar real kembar ($x_1 = x_2$)
  • $D < 0 \Rightarrow$ akar tidak real

4. Sifat Akar & Menyusun PK Baru

Jumlah akar: $$x_1 + x_2 = -\frac{b}{a}$$

Hasil kali akar: $$x_1 \cdot x_2 = \frac{c}{a}$$

PK baru dari akar $x_1, x_2$: $$x^2 - (x_1 + x_2)x + (x_1 \cdot x_2) = 0$$
